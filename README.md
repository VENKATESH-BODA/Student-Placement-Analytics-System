# Student Placement Analytics System

## Overview
This project analyzes student placement data using Python, SQL, Excel, and Power BI.

## Technologies Used
- Python
- Pandas
- MySQL
- Power BI
- Excel

## Features
- Placement trend analysis
- Salary analysis
- CGPA insights
- Company hiring analysis
- Interactive dashboard

## Tools Used
- Python
- MySQL
- Power BI
- Excel

## Insights
- Students with higher CGPA received better packages.
- CSE students had the highest placements.
- Python and SQL were common skills among placed students.
